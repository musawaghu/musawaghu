## Featured Projects

### 🏛️ [FIRM FLOW](https://github.com/musawaghu/FirmFlow): AI onboarding for architecture firms
**[Live demo](https://firmflow-iota.vercel.app)** · Built at an AEC hackathon with a five-person team

Turns a firm's existing onboarding manual into structured, interactive onboarding, without letting the AI invent anything. Every rewritten passage links back to its source, unsupported content is flagged for review, and a "Who do I ask?" assistant routes new hires to real people from the firm's directory.

- **My role:** lead technical architect (chose the stack), backend and database, and originated the manual enhancer and AI assistant concepts
- **Stack:** Python, FastAPI, Supabase (Postgres), Claude API, React, TypeScript, Google Cloud Run, Vercel

### 🧠 [Brain Tumor Detection](https://github.com/musawaghu/Brain-Tumor-Detection-DL): MRI classification with explainability
Fine-tuned ResNet-50 classifier that detects glioma in brain MRI scans, tuned with recall in mind, because a missed tumor costs far more than a false alarm.

- **Upgrading:** held-out test evaluation, Grad-CAM heatmaps that show where the model is looking, and an upload-and-predict web demo
- **Stack:** Python, PyTorch, torchvision, scikit-learn

### 👷 [Jobsite Check-In](https://github.com/musawaghu/Realtime-Facial-Recognition): face recognition for construction sites *(in progress)*
Evolving my real-time face recognition pipeline (MTCNN + FaceNet) into a gate check-in system for construction sites: accurate hours for payroll, a live on-site roster, and a one-click emergency muster list. Designed privacy-first, with explicit consent, embeddings only (no photos stored), and automatic deletion.

- **Stack:** Python, PyTorch, OpenCV, FastAPI

### ⚡ Parallel SIFT: why more threads didn't help *(rebuilding)*
My undergraduate senior research parallelized SIFT feature extraction for content-based image retrieval by splitting images into tiles across threads. The speedup never appeared, and the reason was Python's GIL. This rebuild benchmarks serial vs. threads vs. processes and shows the fix.

- **Stack:** Python, OpenCV, NumPy, multiprocessing

### 🏙️ [NYC Airbnb Analysis](https://github.com/musawaghu/Airbnb_Data_Analysis): pricing and neighborhood insights
Cleaned and modeled 2019 NYC Airbnb listings in SQLite, then explored pricing, room types, and availability by neighborhood in Python and a Power BI dashboard.

- **Stack:** Python, pandas, SQL, SQLite, Power BI

### 🩺 Sihha: clinical NLP platform *(early stage)*
A solo founder project to build a HIPAA-compliant clinical NLP platform. Currently in the product design phase.
